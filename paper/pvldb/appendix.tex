\section{Overlap with the conversational-risk manuscript}

\begin{sloppypar}
The arXiv paper 2607.19361, ``Stateful Guardrails for Multi-Turn LLM Systems,'' studies dialogue. It scores semantic drift, a graph of entities mentioned in the text, and a compliance gradient. Its benchmarks are synthetic multi-turn conversations.
\end{sloppypar}

This paper studies SQL answers. The session state is the weight vector of entities behind an aggregate, not the text of the dialogue. The shared idea is that a score accumulated over a session can be confounded with length, which is why the finance sessions are length-matched in the earlier TKDE draft and why this paper refuses a query instead of alarming on session length.

\begin{sloppypar}
No table, figure, or paragraph from arXiv:2607.19361 is copied here. The TKDE readme calls the journal version a TIFS manuscript. That draft is not in this repository. The review asked for a TDSC citation. The bibliography entry records the conflict and asks the author to confirm the venue.
\end{sloppypar}

\section{Not run}

\begin{itemize}
\item A local open-weight attacker with a budget of 100 queries. No Ollama server was listening. The harness refuses to fall back to a paid API.
\item Snowflake and BigQuery at $k{=}3,5,10$. \texttt{vendor\_k\_sweep.py} exits before opening a connection.
\item OpenDP and Tumult Analytics. The minimum-group baseline is our own Laplace code.
\item Spider 2.0. There is no agent-numbers file in the repository.
\item A second BIRD audit log. Only one committed log exists.
\end{itemize}
